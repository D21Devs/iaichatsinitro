    Blocos de Conhecimento
    Os blocos são injeções de instrução enviadas ao agente antes de cada conversa. Eles definem comportamento, regras, tom e informações do produto. Você pode ter quantos blocos quiser e controlar individualmente quais estão ativos.
    1
    Clique em "+ Novo" no painel esquerdo

    Um modal abrirá pedindo nome, categoria e conteúdo do bloco.

    2
    Escolha uma categoria

    A categoria organiza o bloco e é usada como filtro nos testes. Use base para instruções gerais e escalonamento para regras de encaminhamento.

    3
    Escreva o conteúdo do bloco

    Use linguagem direta e imperativa. Ex: "Quando o cliente mencionar 'sinistro', peça o número do contrato antes de qualquer outra informação."

    4
    Use o toggle para ativar/desativar

    Blocos desativados ficam visíveis na lista mas não são enviados ao agente. Ideal para testar o efeito de remover uma instrução sem excluí-la.

    Chat ao Vivo
    O painel central exibe o widget do chatbot em tempo real. Use para validar manualmente qualquer mudança feita nos blocos antes de rodar a bateria de testes automáticos.
    1
    Digite como se fosse um usuário real

    Teste os cenários mais comuns: abertura de sinistro, dúvidas sobre cobertura, solicitação de falar com humano, pedido de número de contato.

    2
    Observe a resposta do agente

    Verifique se o tom está correto, se as informações são precisas e se o escalonamento acontece na hora certa.

    3
    Edite um bloco e clique ↺ Reset

    Toda alteração nos blocos é aplicada imediatamente. Use o botão ↺ Reset para limpar o histórico e começar uma nova conversa com as instruções atualizadas.

    Testes Automáticos
    A aba ▶ Rodar executa uma bateria de perguntas predefinidas e calcula um score de aprovação. É a forma mais rápida de medir se uma alteração nos blocos melhorou ou piorou o agente.
    1
    Selecione a categoria (opcional)

    Rode "Todas as categorias" para um score geral, ou filtre por uma categoria específica para diagnósticos mais rápidos.

    2
    Ative o Juiz LLM se quiser análise qualitativa

    Com o juiz ligado, o DeepSeek avalia empatia, precisão e clareza de cada resposta além do teste binário de keywords. Mais lento, mais rico.

    3
    Clique ▶ Rodar e acompanhe em tempo real

    Os resultados aparecem conforme os testes são processados. OK = passou, FAIL = falhou.

    4
    Clique em um item FAIL para ver o detalhe

    O modal de detalhe mostra a resposta completa do agente, a keyword que faltou e a avaliação do juiz.

    5
    Salve a versão se o score melhorou

    Use o botão 💾 Salvar para guardar um snapshot dos blocos com o score atual. Você pode restaurar qualquer versão anterior com um clique.

    Criando e Editando Testes
    A aba Testes lista todos os casos de teste. Cada caso define uma pergunta, o comportamento esperado (ação) e critérios de aprovação por keywords. Quanto mais testes, mais confiável o score.
    1
    Vá na aba Testes e clique "+ Novo"

    Um modal abrirá com os campos do caso de teste.

    2
    Escreva a pergunta como o usuário digitaria

    Use linguagem natural e informal. Ex: "preciso abrir um sinistro meu carro bateu" em vez de "Solicitar abertura de sinistro veicular."

    3
    Defina a Action esperada

    null = resposta normal de texto. redirect = agente deve enviar link do portal. phone = agente deve sugerir WhatsApp.

    4
    Adicione Keywords obrigatórias

    Palavras que DEVEM aparecer na resposta. O teste falha se o agente não mencionar. Use termos-chave como "portal", "sinistro", "protocolo".

    5
    Adicione Palavras proibidas (opcional)

    Palavras que NÃO devem aparecer. Útil para detectar alucinações: proíba "garantia total", "100%", "sempre aprovado".

    Simulações LLM
    O sistema de Simulações usa inteligência artificial para simular um usuário real conversando com o agente. Ao final, um juiz DeepSeek avalia toda a conversa com notas e feedback detalhado.
    1
    Clique em "+ Nova Persona"

    Uma persona é o perfil do usuário simulado: quem é, o que quer, como se comporta.

    2
    Preencha o Contexto

    Descreva quem é essa pessoa. Ex: "Mulher de 52 anos, bateu o carro no estacionamento do trabalho, nunca abriu sinistro antes, está nervosa."

    3
    Defina o Objetivo

    O que ela quer conseguir na conversa. Ex: "Quer abrir o sinistro, entender se a cobertura inclui colisão em estacionamento e saber o prazo."

    4
    Configure a Escalação esperada e os turnos

    Se a persona deveria ser encaminhada ao portal (redirect) ou WhatsApp (phone), defina isso. O juiz avaliará se o agente escalou corretamente.

    5
    Clique ▶ Simular e aguarde

    O sistema roda a conversa automaticamente. Ao final, o juiz DeepSeek analisa empatia, precisão, fluidez, objetivo e escalação.
